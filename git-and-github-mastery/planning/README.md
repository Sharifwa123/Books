# Planning documents (historical)

These documents were written **before the manuscript** (architecture, curriculum, gap analysis, licensing options, publishing plans). They record how the book was designed and are kept for that reason; they describe the project as it was then, and some of their statements (for example "drafting not started" or "licence undecided") are **out of date**. For the current state read the book's `README.md`, `publishing/` and `research/README.md`.
