## Baseline facts
- Copyright generally arises automatically on creation of an original work; registration/deposit may exist and matter in some jurisdictions.
- Copyright ≠ licence. A public repository or freely downloadable PDF is not automatically reusable by others.
- Licensing is a separate decision from writing. Code samples and prose can be licensed differently.

## Option B — Creative Commons for the text
| Licence | Others may | Conditions |
|---------|-----------|------------|
| CC BY | reuse, adapt, sell | credit |
| CC BY-SA | reuse, adapt, sell | credit + share adaptations under same licence |
| CC BY-NC | reuse, adapt non-commercially | credit + no commercial use |
| CC BY-ND | redistribute unchanged | credit + no adaptations |
| CC BY-NC-SA | adapt non-commercially | credit + non-commercial + share-alike |
| CC BY-NC-ND | share unchanged, non-commercially | credit + no derivatives + non-commercial |
| CC0 | anything | dedicates to public domain where possible |

Notes: CC licences suit copyrightable prose/images; CC itself recommends not using them for software. NC/ND variants are less compatible with open-educational-resource norms.

## Option C — Open educational publication
Free to read/download, copyright retained by SHARIF TECHNOLOGIES, with a written permissions statement (e.g. classroom use allowed, redistribution/commercial use requires permission).
