# Sunrise Bakery starter files

A three-page fictional bakery website used as the running example in *Git & GitHub: From Zero to Mastery*.
You do not need to write or understand HTML or CSS to follow the book; you only need to edit, save and track these text files.

- `index.html`, `menu.html`, `contact.html`: the three pages (plain text files)
- `css/style.css`: the appearance (plain text)
- `images/logo.svg`: a small logo, stored as text (an SVG image is text; a PNG would be a binary file)

Sunrise Bakery is fictional. Address and telephone number are placeholders.
