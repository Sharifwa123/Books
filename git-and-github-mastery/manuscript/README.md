# Manuscript

The complete draft: 81 chapters in 13 parts, 14 appendices, front matter and back matter. All 81 chapters were drafted and have had a full editorial read-through; the book is **not published** (see `../publishing/final-publication-blockers.md`).

- `front-matter/`: title page, copyright and notices, contents, preface, how to use this book (generated by `../tools/build_frontmatter.py`).
- `parts/pNN-name/chNN-title.md`: the chapters, one file each. Exercises are in `../exercises/` and solutions in `../solutions/`; the builders append them to their chapters.
- `appendices/`: Appendices A to N (E, F and N are generated by `../tools/build_backmatter.py`).
- `back-matter/`: glossary and the author and publisher page (generated).

Cross-references between chapters are written with a key and expanded to numbers by `../tools/resolve_refs.py`.
