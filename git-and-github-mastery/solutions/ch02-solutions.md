## Level 5
**5.1** Renaming changes only the label (the extension). The contents are still SVG text, so a program that trusts the `.png` label tries to read it as a PNG image and fails. To obtain a real PNG, use a program that *converts* the picture (export or save-as PNG), which rewrites the contents.

**5.2** One person's file system treats names that differ only in capitals as the same, so it can hold only one of the two files (or one overwrote the other). Rule: never create names that differ only by capitalisation; use lowercase names.
