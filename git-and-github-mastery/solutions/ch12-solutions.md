# Chapter 12 solutions

## Level 1
**1.1** Git is the version-control system; GitHub is an online platform built around Git repositories and collaboration on software. Camera/photo-site: Git takes and keeps the photos on your device; GitHub is the site that stores copies so others can see and discuss them.

## Level 2
**2.1** Git: recording a version; comparing two versions; creating a branch. Platform: opening an issue; reviewing a proposed change; a profile page.

## Level 3
**3.1** A good reply: Git is a separate program that works on your own computer, with no account; you can learn all the recording, comparing, branching and merging locally (Part III does exactly that); GitHub comes later, in Part V, and you can create the account then.

## Level 4
**4.1** The commands, the concepts and the way of working stay the same. The decision is about the platform: where it runs, its review and automation features, access control, cost and support.

## Level 5
**5.1** A platform holds *a* copy of the history; every contributor's clone holds a complete copy (Chapter 11<!--ref:distributed-->). Check whether a local clone exists and, if so, copy the history back to a new shared repository.

**5.2** Pull requests belong to the platform, so Git's own documentation does not describe them (in the sense used here). The platform's documentation is the place to look (Chapter 45<!--ref:pr-->).
