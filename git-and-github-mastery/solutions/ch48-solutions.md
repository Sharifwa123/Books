# Chapter 48 solutions

## Level 1
**1.1** (a) discussion (Q&A); (b) issue; (c) pull request; (d) discussion.

**1.2** Announcements, General, Ideas, Polls, Q&A, Show and tell.

## Level 2
**2.1** Open an issue for the action and link the discussion.

**2.2** For example: mark an answer in a Q&A discussion once a comment solves it; lock a conversation that violates the code of conduct.

## Level 3
**3.1** Answers vary. For example: Announcements (announcement), Q&A (question and answer), Ideas (open-ended), Show and tell (open-ended).

## Level 4
**4.1** Create a Q&A category, point the contributing guidelines and the issue chooser to it for usage questions, and keep issues for reproducible bugs and planned work. Convert misfiled issues to discussions.

## Level 5
**5.1** An administrator has not enabled Discussions for the repository, or the person does not have access to the repository.

**5.2** Lock the discussion (it is a documented use of locking for announcements), and point people to another category for comments.
