# Chapter 11 solutions

## Level 1
**1.1** Centralised: a central box holding the full history; three people each with a working copy only. Distributed: each person's computer holds a full repository; optionally a shared repository on a server, also full.

## Level 2
**2.1** (a) distributed; (b) centralised (by design; in a distributed team by agreement); (c) distributed; (d) centralised.

## Level 3
**3.1** "Teams usually choose one shared repository as the meeting place, by convention. It is a copy like any other, and each person still has the whole history."

## Level 4
**4.1** Distributed. Points: works offline; every copy is a backup; private experiments; fast. The group must agree which shared repository is official and how changes reach it (a workflow, Chapter 34<!--ref:workflows-->).

## Level 5
**5.1** The local repository holds the complete history, not only the latest files; the copy on a platform is another complete copy.

**5.2** The half who say work can continue. Everyone can still read history, record work, branch and merge locally. What cannot happen until the server returns is exchanging history through it (sharing and receiving others' work), although people could exchange directly or use another shared repository.
