# Chapter 1 solutions

Read these only after attempting the exercises.

## Level 1
**1.1** Answers depend on your computer. A correct answer names the operating system family (Windows, macOS or Linux) and a version.

**1.2** Sample answers for a laptop: input device: keyboard or touchpad; output device: screen or speakers; storage: the internal solid-state drive. Any real example of each kind is correct. A touch screen is both an input and an output device.

## Level 2
**2.1** (a) storage: it is kept although the device may have been switched off. (b) memory: it has not been saved, so it exists only in the fast temporary workspace. (c) memory: a running program is loaded into memory while it runs. (Its installed files, before running, are in storage.)

**2.2** Top to bottom: you; applications (for example a browser, an editor); operating system (for example Windows, macOS or Linux); hardware (processor, memory, storage, screen, network adapter). Requests flow down and results flow back up.

## Level 3
**3.1** A good explanation sounds like: "While you type, the computer keeps your words on a fast, temporary desk. If the power goes, the desk is cleared. Saving copies the words into a cupboard that keeps things when the power is off." Any explanation that keeps the temporary/permanent distinction is correct.

## Level 4
**4.1** Suggested steps: (1) do not install yet; (2) ask where the advertisement led and who makes the program; (3) look for the maker's own website through a separate search, not the advertisement; (4) check whether the task can be done with a tool your organisation already approves or a web version; (5) if it is approved, install it from the official source; (6) refuse the administrator prompt if it appears without a clear reason. Two questions for the colleague: "Who told you about it, and can you show me the address you downloaded it from?" and "What exactly do you need it to do?"

## Level 5
**5.1** (a) The computer is not broken. The essay was unsaved, so it existed only in memory, which is emptied when the power is lost. The photos were saved in storage, which keeps information without power. (b) Save early and often; use a program's automatic-save or auto-recovery feature if it has one; keep a copy on a second device or in an online service.
