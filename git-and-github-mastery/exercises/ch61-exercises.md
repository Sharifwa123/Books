# Chapter 61 exercises — Actions vs External CI

Attempt each exercise before you open `solutions/ch61-solutions.md`. These exercises are on paper.

## Level 1 — Guided

**1.1 Two kinds.** Name the two kinds of status check on GitHub and who creates each.

**1.2 Which one?** Which kind does a GitHub Actions workflow create?

## Level 2 — Partially guided

**2.1 Required.** Can a result from a system other than Actions be a required status check? Explain in one sentence.

**2.2 Portable.** Give one advantage of keeping the real work in scripts in the repository.

## Level 3 — Independent

**3.1 A checklist.** Choose four questions from section 61.3 and answer them for the CI system you use or plan to use, looking up current documentation.

## Level 4 — Professional scenario

**4.1 A proposal.** A team wants to move from an external CI service to Actions. Write five questions to settle before they decide.

## Level 5 — Troubleshooting

**5.1** A required check named `build` never appears on a pull request from an external system, and the merge is blocked. Give two things to look at.
