# Chapter 65 exercises — Copyright and Licences

Attempt each exercise before you open `solutions/ch65-solutions.md`. These exercises are on paper. **None asks you to give legal advice.**

## Level 1 — Guided

**1.1 Two words.** Explain copyright and licence in one sentence each.

**1.2 No licence.** A repository has code but no licence file. According to GitHub's documentation, what applies?

## Level 2 — Partially guided

**2.1 Read a table.** Using the table in section 65.3, say which of MIT, Apache-2.0 and GPL-3.0-only requires source of a larger work that uses the code to be shared under the same licence.

**2.2 The seven questions.** For a project you know, answer the seven distinctions with "stated", "not stated" or "unclear", after reading its licence.

## Level 3 — Independent

**3.1 Decode.** Explain `CC-BY-NC-SA-4.0` element by element.

**3.2 A name.** Why should you use `GPL-3.0-only` rather than `GPL-3.0`?

## Level 4 — Professional scenario

**4.1 A reuse request.** A colleague wants to copy a function from a public repository that has no licence into a company product. Write a reply based on this chapter, without claiming legal certainty.

## Level 5 — Troubleshooting

**5.1** You copied code from a project whose licence requires keeping the copyright notice, and you removed it. What is the first thing you do?

**5.2** Two libraries you use have different licences and you are unsure they can be combined. Where do you look, and whom do you ask?
