# Chapter 36 exercises — What GitHub Is (and Is Not)

Attempt each exercise before you open `solutions/ch36-solutions.md`. None of these needs a GitHub account or an internet connection. Use `bakery-menu` (rebuild it from Chapter 17<!--ref:history_view--> if needed).

## Level 1 — Guided

**1.1 Two sentences.** Write one sentence saying what Git is and one saying what GitHub is, without using the word "GitHub" in the first.

**1.2 Add an address.** Run `git remote add origin https://github.com/example-owner/sunrise-bakery.git` in a practice repository, then `git remote -v`. What do the two lines show?

## Level 2 — Partially guided

**2.1 Read the address.** Label the scheme, the host, the owner and the repository name in `https://github.com/example-owner/sunrise-bakery.git`.

**2.2 No connection yet.** Run `git branch -vv` and `git config --get remote.origin.url`. Why does `main` show no remote branch?

## Level 3 — Independent

**3.1 Git or platform?** For each item, decide whether it is part of Git or a platform feature: a commit; a pull request; a branch; an issue; a tag; a release page; a `.gitignore` file.

**3.2 What a clone brings.** In your own words, list what `git clone` copies and what it does not.

## Level 4 — Professional scenario

**4.1 Explain it to a colleague.** A colleague says: "We use GitHub, so we do not need Git." Write a short, kind explanation with two examples from this book.

## Level 5 — Troubleshooting

**5.1** A learner says: "I cloned the project, but the issues are missing." What is the misunderstanding?

**5.2** A learner says: "My code is on GitHub, so I have a backup." List two ways in which that can be untrue.

**5.3** A learner finds a GitHub tutorial with different buttons from the ones on their screen. Give two possible reasons and one action.
