# Chapter 8 exercises — Markdown in Five Pages

Attempt each exercise before you open `solutions/ch08-solutions.md`. Use a text editor, and a Markdown preview if it has one.

## Level 1 — Guided

**1.1 A first document.** Create `notes.md` containing: a first-level heading `Study notes`, a paragraph of one sentence, and a bulleted list of three items. *Expected result:* the preview shows a heading, a paragraph and three bullets.

**1.2 A link and an image.** Add a link to `menu.html` with the words "our menu", and an image reference to `images/logo.svg` with the alternative text "Sunrise Bakery logo". *Expected result:* a clickable link; the image if the file exists.

## Level 2 — Partially guided

**2.1 A table.** Write a table with the columns `Item` and `Price` and three rows. Hint: the second row is dashes. Then delete the dashed row and describe what changes.

**2.2 Paragraphs.** Write two sentences on separate lines with no blank line, and one pair with a blank line between. How many paragraphs does the preview show for each?

## Level 3 — Independent

**3.1** Write a `README.md` for a project of your own choosing (a school club site, a recipe collection) with: a title, a one-paragraph description, a section headed `How to use`, a numbered list of three steps, and a code block showing one command. Preview it.

## Level 4 — Professional scenario

**4.1** A colleague sends the volunteer rota as a `.docx` and asks you to publish it on the project page so people can see changes over time. Convert the first six rows to a Markdown table, and write two sentences explaining why the Markdown version is better for tracking changes and one situation in which the `.docx` would still be better.

## Level 5 — Troubleshooting

**5.1** A learner's list renders as a single paragraph with dashes in it. The source is:

```
Ingredients:
- flour
- water
```

and the other renderer they use needs a blank line before a list. What is the fix, and why is it a good habit even when the renderer does not need it?

**5.2** A table shows as plain lines of `|` characters. List two possible causes in order of likelihood.

**5.3** A link in a README works on your computer but not for a friend who opened the project in another folder structure. What kind of path did you probably use, and how would you make it robust?
