# Chapter 41 exercises — Notifications, Stars and Watching

Attempt each exercise before you open `solutions/ch41-solutions.md`. These exercises need a browser and a GitHub account; if you have none yet, do the paper versions (1.1, 2.1, 3.1, 5.1), which need only the chapter.

## Level 1 — Guided

**1.1 Three actions.** Write one sentence each for *watch*, *star* and *follow*. Which of the three subscribes you to notifications?

**1.2 Find your places.** On your account, find the notification settings and the page that lists the repositories you watch. Write down the two addresses (the page names, not the buttons).

## Level 2 — Partially guided

**2.1 Why did I get this?** A notification is labelled `subscribed`, and you never pressed Watch. List two things from section 41.2 that could explain it.

**2.2 Set a level.** Choose a repository you do not maintain. Set it to notify you only when you take part or are mentioned. Say what you will no longer receive.

## Level 3 — Independent

**3.1 A filter.** Write the inbox query that shows only the notifications where your review was requested.

**3.2 Clean-up.** Open the page of watched repositories. Unwatch at least three that you do not need. Write down how many you watched before and after.

## Level 4 — Professional scenario

**4.1 A busy project.** You have joined a project that produces about 200 notifications a day. Write a plan of five steps (watch levels, filters, addresses, a routine for Done and Save) that keeps you informed about mentions and review requests only.

## Level 5 — Troubleshooting

**5.1** A learner set a repository to **Ignore** to stop the noise, and later a teammate mentioned them in a question that went unanswered. Explain what happened and what setting they should have chosen.

**5.2** A learner says that notifications from last spring have vanished from the inbox. What is the likely reason, and what should they have done with the ones they wanted to keep?
