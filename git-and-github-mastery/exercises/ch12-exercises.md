# Chapter 12 exercises — Git, GitHub, GitLab, Bitbucket

Attempt each exercise before you open `solutions/ch12-solutions.md`.

## Level 1 — Guided

**1.1 Complete the sentences.** "Git is …, and GitHub is …." Then write the camera-and-photo-site analogy in your own words.

## Level 2 — Partially guided

**2.1 Tool or platform?** Sort into "Git (tool)" or "platform": recording a version; opening an issue; comparing two versions; reviewing a proposed change; creating a branch; a profile page.

## Level 3 — Independent

**3.1** A friend says: "I don't want a GitHub account, so I can't learn Git." Write a two-paragraph reply.

## Level 4 — Professional scenario

**4.1** Your organisation must keep its code on its own servers. Explain, using section 12.4.1, which of your team's Git skills stay the same and which parts of the decision are about the platform.

## Level 5 — Troubleshooting

**5.1** Someone says: "GitHub lost our history when it went down." What is wrong with that sentence, and what would you check?

**5.2** A colleague searches Git's documentation for "pull request" and finds nothing useful. What has happened, and where should they look?
