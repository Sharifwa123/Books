# Chapter 43 exercises — Repository Settings, Security Tab and Wiki Tour

Attempt each exercise before you open `solutions/ch43-solutions.md`. Exercises 1 to 3 need only your computer.

## Level 1 — Guided

**1.1 A wiki stand-in.** Create a bare repository `demo.wiki.git`, clone it, add `Home.md`, commit and push. Which two histories now exist, and where?

**1.2 Four factors.** List the four things that decide which tabs you see on a repository.

## Level 2 — Partially guided

**2.1 Add a page.** Clone your stand-in again to a second folder, add `Recipes.md` there, and push. Then pull in the first clone. What did the pull bring?

**2.2 A branch on the wiki.** Push a branch `draft` to the stand-in with one new page. According to the chapter, will the page be live on a real wiki? Why or why not?

## Level 3 — Independent

**3.1 Wiki or docs?** For a project with five contributors and outside readers, decide whether the long documentation belongs in a wiki or in a `docs` folder. Give two reasons from section 43.4.

**3.2 The deletion checklist.** Write a five-item checklist to complete before deleting a repository.

## Level 4 — Professional scenario

**4.1 Going public.** A team wants to make a private repository public. Using section 43.2, list the consequences to check first, and one action to take before the change.

## Level 5 — Troubleshooting

**5.1** A colleague says "my security tab is called something different from yours". Give the likely reason, and say whether it is a problem.

**5.2** A learner deleted a repository last month and wants it back. What does the documentation say about the time limit, and what other condition can prevent restoration?
