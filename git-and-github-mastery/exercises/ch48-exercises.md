# Chapter 48 exercises — GitHub Discussions

Attempt each exercise before you open `solutions/ch48-solutions.md`. These exercises are on paper.

## Level 1 — Guided

**1.1 Which one?** For each item choose discussion, issue or pull request: (a) "How do I install it on Windows?"; (b) "The menu prints 3.00 but the file says 3.20"; (c) a spelling fix in the README; (d) "Should we support two languages?"

**1.2 Categories.** Name the six default categories.

## Level 2 — Partially guided

**2.1 A decision.** A discussion in Ideas reaches agreement to add a "kids' menu". What should happen next, according to section 48.2?

**2.2 Moderation.** Name two moderation actions and one situation for each.

## Level 3 — Independent

**3.1 Design categories.** For a small open-source library, choose four categories, and for each say the format and why.

## Level 4 — Professional scenario

**4.1 A noisy project.** A maintainer is flooded with support questions in issues. Propose a way to use Discussions to reduce the load, and how to tell contributors.

## Level 5 — Troubleshooting

**5.1** A contributor cannot find the Discussions tab in a repository. Give two possible reasons.

**5.2** An announcement discussion keeps receiving off-topic comments. What can a moderator do?
