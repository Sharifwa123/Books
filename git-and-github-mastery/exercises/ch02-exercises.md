# Chapter 2 exercises — Files, Folders and Paths

Attempt each exercise before you open `solutions/ch02-solutions.md`. These exercises use only your file manager; no commands are needed.

## Level 1 — Guided

**1.1 Show extensions.** Find the setting in your file manager that shows file name extensions (search the help for "file name extensions"; wording varies). Turn it on.
*Expected result:* file names such as `report.docx` or `photo.jpg` are shown in full.

**1.2 Build the tree.** In your home folder create `sharif-git-lab`, and inside it `sunrise-bakery`, and inside that `css` and `images`.
*Expected result:* four folders in a three-level tree.

## Level 2 — Partially guided

**2.1 Read the address.** The absolute path `/home/learner/sharif-git-lab/sunrise-bakery/css/style.css` is given. Name each folder from the root down, then name the file. Hint: split at every slash.

**2.2 Relative directions.** You are inside `sunrise-bakery/css`. Write relative paths to: (a) `style.css`; (b) `menu.html` in `sunrise-bakery`; (c) `logo.svg` in `sunrise-bakery/images`.

## Level 3 — Independent

**3.1** Design a folder tree for a school project that has a report, three photos and a spreadsheet of results. Write the name of every folder and file, following the naming habits in section 2.1.1. Explain in two sentences why you grouped things the way you did.

## Level 4 — Professional scenario

**4.1** A colleague sends you a folder called `Final Report NEW (2)` containing files named `Chapter One FINAL.docx`, `chapter one final v2.docx` and `IMG 0042.JPG`. Propose a tidy structure and new names. Say which names you changed and why. Which changes would help you when a program later has to be told the path to a file?

## Level 5 — Troubleshooting

**5.1** A learner writes: "I renamed `logo.svg` to `logo.png` so it would be a PNG picture, but now my website shows a broken image." Explain what happened using the word *extension*, and say how to get a real PNG.

**5.2** Two people share a project. On one person's computer, `Menu.html` and `menu.html` both exist. On the other person's computer only one of them appears. Give a possible explanation and a rule that avoids the problem.
