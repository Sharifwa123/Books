# Chapter 47 exercises — GitHub Projects

Attempt each exercise before you open `solutions/ch47-solutions.md`. These exercises are on paper; a real project on your account is optional.

## Level 1 — Guided

**1.1 Layouts.** For each of table, board and roadmap, write one question it answers well.

**1.2 Fields.** Name the five kinds of custom field and one example use of each.

## Level 2 — Partially guided

**2.1 Write filters.** Write a filter for: (a) items with the label `bug` and the status `In progress`; (b) items with the label `bug` or `support`; (c) items assigned to you and not updated for five days.

**2.2 Triage.** Write the filter for a triage view of items without a label and without an assignee in the repository `octocat/game`.

## Level 3 — Independent

**3.1 Design a project.** For the Sunrise Bakery website, design a project: the statuses, two custom fields, and three views (with layout and filter for each).

## Level 4 — Professional scenario

**4.1 A public project.** A team wants a public roadmap for a product whose code is in private repositories. What can the public see, what can they not see, and what should the team avoid writing?

## Level 5 — Troubleshooting

**5.1** A new item added while a view is filtered by `status:"In progress"` appears with the status In progress, and the author did not set it. Explain.

**5.2** A closed issue still shows Todo in the project. What built-in workflow should you check?
