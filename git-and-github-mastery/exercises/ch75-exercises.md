# Chapter 75 exercises — Other Platform Features

Attempt each exercise before you open `solutions/ch75-solutions.md`. Exercises 2.1 and 2.2 use your terminal only. **None asks you to sign up for anything or to spend money.**

## Level 1 — Guided

**1.1 Where?** Where does `FUNDING.yml` live, and on which branch must it be?

**1.2 Limits.** State the two limits on the sponsor button that the chapter mentions.

## Level 2 — Partially guided

**2.1 Write it.** In a sandbox repository, write a `.github/FUNDING.yml` with one GitHub username (a made-up one), one made-up Patreon name and one quoted custom URL, and read it back.

**2.2 Count.** Parse the file with a YAML parser and count the entries per key.

## Level 3 — Independent

**3.1 A rule the parser did not enforce.** Explain why the chapter tells you to follow the documentation's quoting rule even though the parser accepted an unquoted URL.

**3.2 A property plan.** Design two custom properties for an organisation with 40 repositories and say which ruleset each would help you write.

## Level 4 — Professional scenario

**4.1 A policy for tools.** Write five lines for your team's contribution guide about changes that were made with an AI tool, using the chapter. Do not assume the tool is good or bad.

## Level 5 — Troubleshooting

**5.1** The Sponsor button does not appear. List three things to check from the chapter.

**5.2** An app from the Marketplace asks for permissions that seem too broad. What do you do before installing it?
