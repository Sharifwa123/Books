# Chapter 35 exercises — Reading Official Documentation

Attempt each exercise before you open `solutions/ch35-solutions.md`. These exercises use only your own computer.

## Level 1 — Guided

**1.1 Your version.** Run `git --version`. Write down the number. Where else could you check it?

**1.2 A usage text.** Run `git tag -h`. Copy the first form of the synopsis.

## Level 2 — Partially guided

**2.1 Read a synopsis.** For the first form of `git tag`, list which parts are optional, which is required, and which are placeholders.

**2.2 Alternatives and repeats.** In `git tag -d <tagname>...`, what does `...` allow you to do? Try it with two tags in a scratch repository.

## Level 3 — Independent

**3.1 A different command.** Run `git switch -h` and `git restore -h`. For each, write the meaning of two options in your own words, and test both in a scratch repository.

**3.2 The manual.** Try `git help commit`. What happens on your system: a manual page, a web page, or a message? Write down how you would read the manual on this computer.

## Level 4 — Professional scenario

**4.1 A dated answer.** You find a forum post from several years ago that says: "Run this Git command to fix your problem." List four checks you make before you run it, and the scratch-repository test that you would do first.

## Level 5 — Troubleshooting

**5.1** A learner mistypes `git comit` and searches the web for an hour. What should they have read first?

**5.2** A learner follows a tutorial and gets different output from the tutorial's screenshot. Give three possible reasons, related to this chapter.

**5.3** A learner cannot tell whether a feature belongs to Git or to their hosting platform. How can they decide where to look?
