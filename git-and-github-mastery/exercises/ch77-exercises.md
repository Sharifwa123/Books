# Chapter 77 exercises — Capstone Project

Attempt each exercise before you open `solutions/ch77-solutions.md`. The capstone itself (Project 12) is the main exercise; these tasks support it. Work in a sandbox with a local bare repository as the remote. **Do not add a licence text from this book; choosing one is your decision.**

## Level 1 — Guided

**1.1 Repeat steps 1 to 5.** Create the shared repository, your clone, the first files, the pipeline script and the first push. Show `git status -sb`.

**1.2 Read the pipeline.** Explain what each line of `ci.sh` checks and what its exit status means for a real CI system.

## Level 2 — Partially guided

**2.1 Steps 7 and 8.** Add a different feature (for example a tax rate) test-first: show the failing test, then the passing one.

**2.2 Steps 9 and 10.** Play the reviewer with a second clone. Write three review comments (in a text file) and answer them with a follow-up commit.

## Level 3 — Independent

**3.1 A different idea.** Repeat all 23 steps with an idea of your own. List which steps you had to change and why.

**3.2 The GitHub column.** For five steps, perform the "On GitHub" action on a repository you own, and write down every difference between the recording and what you saw.

## Level 4 — Professional scenario

**4.1 Handover.** Write a one-page handover for a new colleague that explains the project's workflow, using the 23 steps as the outline.

## Level 5 — Troubleshooting

**5.1** In step 14 the squash merge reports a conflict. What does that tell you about the branch, and what do you do?

**5.2** Step 21 was pushed by mistake. Write the order of actions, using Chapters 33<!--ref:gitsec--> and 63<!--ref:secpractice-->.
