# Chapter 44 exercises — Issues

Attempt each exercise before you open `solutions/ch44-solutions.md`. Exercises 1 to 3 need only your computer.

## Level 1 — Guided

**1.1 A form file.** In `bakery-menu`, create `.github/ISSUE_TEMPLATE/bug.yml` with the form from section 44.4 and commit it. Run `git ls-files .github`.

**1.2 Four things.** Write the four things a good issue says.

## Level 2 — Partially guided

**2.1 A keyword.** Make a small change to `menu.md` and commit it with the body `Fixes #12`. Find it again with `git log --grep='#12'`.

**2.2 Another repository.** Write the closing keyword for issue 100 in the repository `octo-org/octo-repo`.

## Level 3 — Independent

**3.1 A better title.** Rewrite the title "Menu broken" for a case where the roll price differs between two places.

**3.2 Three labels.** Choose three labels a small project could use, and say what each one means. Explain why three is enough.

## Level 4 — Professional scenario

**4.1 A template set.** Design a bug-report form and a question form for a public project. List the fields for each and which are required.

## Level 5 — Troubleshooting

**5.1** A pull request says "Fixes #40", is merged, and issue 40 stays open. Give two possible reasons from section 44.3.

**5.2** A maintainer added an issue form on a branch called `templates`, but contributors still see no form. Explain.
