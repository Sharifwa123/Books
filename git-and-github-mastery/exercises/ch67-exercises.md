# Chapter 67 exercises — Creating an Open-Source Project

Attempt each exercise before you open `solutions/ch67-solutions.md`. Project 11 is in section 67.2 of the chapter. **These exercises do not ask you to choose a licence for anyone else.**

## Level 1 — Guided

**1.1 Five questions.** List the five questions a project should answer quickly and the file that answers each.

**1.2 Missing files.** In the chapter's recording, which two files were reported missing, and why were they left out?

## Level 2 — Partially guided

**2.1 Run it.** Create the `wordcount` project in a sandbox folder up to the first tag. Show `git tag -n1` and `git ls-files`.

**2.2 A third test.** Add a test for a text with a leading and a trailing space. Does the function pass? Run the tests and show the result.

## Level 3 — Independent

**3.1 Your own idea.** Replace `wordcount` with a small idea of your own (for example, a function that reverses the words of a sentence). Follow the same steps and write down what you changed.

**3.2 A check script.** Write a shell loop that reports whether `.gitignore`, `README.md` and `tests` exist.

## Level 4 — Professional scenario

**4.1 A stranger's five minutes.** Imagine a stranger opens your repository. Write what they see in the first minute, and improve three things.

## Level 5 — Troubleshooting

**5.1** Generated `__pycache__` folders appear in `git status` in your project. What do you add, and what do you do if they were already committed?

**5.2** A user asks whether they may use your library in a company product, and you have no licence. What do you tell them, and what should you do about it?
