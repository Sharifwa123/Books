# Chapter 69 exercises — GitHub Pages

Attempt each exercise before you open `solutions/ch69-solutions.md`. Exercises 2.1 and 2.2 use your terminal; nothing needs a GitHub account.

## Level 1 — Guided

**1.1 Two sites.** State the address of (a) a user site and (b) a project site for the account `ada` and the repository `notes`.

**1.2 Two sources.** Name the two ways of choosing what Pages publishes.

## Level 2 — Partially guided

**2.1 Find the faults.** In a sandbox repository, create an `index.html` with one `http://` image and one `href="/style.css"` link. Use `git grep` to find both.

**2.2 Fix and check.** Fix both faults and run the searches again. What does `git grep` print, and what do you add so that the message "none left" appears?

## Level 3 — Independent

**3.1 A checklist script.** Write a small shell script that fails (exit code 1) if `git grep` finds `http://` in your site files.

**3.2 Records.** For `www.example.com` and for `example.com`, name the DNS record types the chapter mentions. Where do you find the actual values?

## Level 4 — Professional scenario

**4.1 A shop.** A friend wants to sell products on a Pages site. Write a reply that uses the chapter's rules of use, without promising what GitHub will decide.

## Level 5 — Troubleshooting

**5.1** After publishing a project site, the page shows without styles. Give two causes from the chapter and how you would confirm each.

**5.2** "Certificate not yet created" appears after you set a custom domain. What does the chapter say happens, and what is its suggested step?
