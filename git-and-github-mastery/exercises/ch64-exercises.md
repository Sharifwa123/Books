# Chapter 64 exercises — How Open Source Works

Attempt each exercise before you open `solutions/ch64-solutions.md`. Exercise 2.1 uses your terminal only.

## Level 1 — Guided

**1.1 Three ideas.** Explain the difference between public, source-available and open source in one sentence each.

**1.2 Role or permission.** For each, say whether it is a role or a permission: maintainer, write access, contributor, admin.

## Level 2 — Partially guided

**2.1 Sign off.** In a new repository, make a commit with `git commit -s` and show its full message with `git log -1 --format=%B`. What line was added?

**2.2 Find the rules.** Pick a public project and list where you looked to find how to contribute.

## Level 3 — Independent

**3.1 The flow.** Write the eight steps of the contribution flow in your own words, with the Git command or GitHub action for each.

**3.2 A small change.** Describe a documentation change that would be a good first contribution, and why it is good.

## Level 4 — Professional scenario

**4.1 A declined pull request.** A maintainer closes your pull request with "thanks, but this does not fit the project". Write your reply and say what you do next.

## Level 5 — Troubleshooting

**5.1** Your pull request has been open for two weeks with no reply. Give three things you can check or do, in order, without being rude.

**5.2** A project requires sign-off and your commit lacks it. What command fixes the most recent commit, and what should you check before signing off?
