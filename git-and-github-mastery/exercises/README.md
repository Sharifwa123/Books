# Exercises

One file per chapter (`chNN-exercises.md`), five levels each: L1 Guided, L2 Partially guided, L3 Independent, L4 Professional scenario, L5 Troubleshooting. Solutions live in `../solutions/`, never inline.

## Publication gate
An exercise may be published only when **every command in it has been executed** and its expected result recorded, on the publication-baseline Git version (and on GitHub, with the account type/visibility stated, for GitHub exercises). `registry.csv` tracks this: nothing is `verified` merely because the behaviour is believed. `EX-revert-empty-commit` is currently **BLOCKED** for exactly this reason.
