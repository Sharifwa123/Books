# Chapter 81 exercises — Final Mastery Assessment

The assessment itself is the exercise. Attempt these reflection tasks after your first run and before you open `solutions/ch81-solutions.md`.

## Level 1 — Guided

**1.1 Predict.** Before you run the checker for the first time, write down which tasks you expect to pass. After the run, compare.

## Level 2 — Partially guided

**2.1 Order.** List the ten Proficient tasks in the order in which you would do them, and say which tasks depend on which.

## Level 3 — Independent

**3.1 Redo with a constraint.** Run the setup again and complete the Proficient tasks using only the manual pages (`git help ...`) and no notes. Record which tasks you needed to look up.

## Level 4 — Professional scenario

**4.1 Explain to a colleague.** Choose three tasks and write a short explanation for a new colleague: what the task is for at work, the command you used, and one mistake to avoid.

## Level 5 — Troubleshooting

**5.1** The checker fails P7, but you are sure you created the tag. List four reasons the check could fail and how you would find out which one applies.
