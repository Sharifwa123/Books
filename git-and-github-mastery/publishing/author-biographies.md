## Extended biography (359 words)

Sharif Tingane Issah is the founder of SHARIF TECHNOLOGIES, the name under which Sharif writes and publishes software and books. Sharif works from Ghana and has kept a public GitHub account since March 2023. The profile there describes the work as software, artificial intelligence and cybersecurity, with the aim of building practical technology.

The most developed software project on the public record is Sharif NOVA, a programming language and toolchain started as an independent project and meant to read like ordinary instructions while still going through a real compiler pipeline. By its own documentation it has a lexer, parser, semantic checker and interpreter, a compiler that turns page descriptions into HTML and JavaScript, and a mode that serves an API and pages together from one file. It has no dependencies, is released under the MIT licence, and first appeared on npm in September 2026. It is at an early version number, and nothing here should be read as a claim about how widely it is used.

Git & GitHub: From Zero to Mastery applies the same insistence on precision to teaching. It starts from what a computer, a file and a path are, for readers who have never used version control, and continues through everyday Git, working on GitHub, automation, security, open-source practice and recovery from mistakes, ending with a practical assessment. Its method is stated in the preface: commands are run, not remembered; the output printed is the output recorded; each claim carries a label saying whether it was run, read in the official documentation, or not checked; and gaps are listed in an appendix instead of being smoothed over.

The book was written with the help of an AI assistant, Claude, made by Anthropic, working under Sharif's direction; the copyright page, the preface and an appendix say what the assistant did, and the repository's history lists Claude as contributor and co-author. The book's working record, including the research ledger, the recorded command sessions and the automated checks that run on every change, is public in the repository it is built from. The book is issued under the slogan that appears on its title page: Knowledge Is Power.
