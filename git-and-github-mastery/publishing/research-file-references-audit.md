# Audit of references to `research/…` files in the book text

`tools/export_clean.py` warns when the book text names a file under `research/`. It found **six** places (the earlier count of five did not include Chapter 8's checking table). For each: what it does, whether a reader needs the filename, whether the file is distributed, and what was done.

The files are **public**: the book's repository (`Sharifwa123/Books`) is public and contains `research/`. A reader who wants to reproduce a check needs to know where the evidence lives, so the references are useful, but a bare development path in running text is unfriendly. Decision: **keep the references, say once where the files are, and word each in reader-facing terms.**

| # | Location | What the reference does | Reader needs the filename? | Replacement |
|---|---|---|---|---|
| 1 | Chapter 8, checking table, row 1: `research/commonmark-conformance.py` | Names the script that reproduces the 655 CommonMark examples | Only a reader who wants to re-run it | "the conformance script in the book's companion repository (`research/commonmark-conformance.py`)" |
| 2 | Chapter 12, checking note: `research/git-verification/verify-git-basics.sh` | Names the recorded test of bare repositories | Only for reproducing the test | "the recorded test (`research/git-verification/verify-git-basics.sh` in the companion repository)" |
| 3 | Chapter 13, checking note: `research/sources-manifest.csv` | Says where the hash of the fetched installer script is | For verifying the hash | Reworded to "the sources manifest in the companion repository" with the path in brackets |
| 4 | Chapter 36, "How GitHub facts are checked": `research/sources-manifest.csv` | Says where the fetched-source record is | Yes, this is the book's source record | Same wording as 3 |
| 5 | Appendix N, introduction: `research/research-ledger.csv` | Names the full ledger file | **Yes**: the appendix summarises it | Keep, and introduce the companion repository by name and address |
| 6 | Appendix N, introduction: `research/sources-manifest.csv` | Names the fetched-source list with hashes | Yes | As 5 |

**The companion repository** is introduced once, in "How to use this book", and in Appendix N: the book's public repository, `https://github.com/Sharifwa123/Books`, folder `git-and-github-mastery`. It holds the recorded sessions, the research ledger, the verification scripts and the companion files.

Remaining decision for the author (small): whether a printed edition should print the repository address or a shorter stable link. If the repository is renamed or moved, the address changes in one place (`manuscript/front-matter/04-how-to-use-this-book.md`, generated by `tools/build_frontmatter.py`) and in Appendix N.
